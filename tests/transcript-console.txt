DipshitOS - AArch64 firmware-assisted kernel monitor
DipshitOS: memory is a map, not a territory.
motd: aarch64 el1 kernel live; scheduler, uaccess, fs, net, gfx, xhci armed.
Type 'help' before touching anything expensive.
dipshit> help
available commands:
machine / identity
  about       explain this questionable system
  beans       count beans, probably
  elephant    operational mascot diagnostics
  sysinfo     comprehensive system and subsystem diagnostic snapshot
  tour        guided tour of the system for new users
  uname       compact system identity
  version     display build information
  welcome     guided tour of the system for new users
memory / machine state
  addrspaces  per-task user address spaces: per-task TTBR0, EL1-only kernel overlay, user-root contents
  fault       trigger a synchronous exception (diagnostic)
  handoff     display boot-to-kernel ABI data
  hex         format an integer in hexadecimal
  mem         summarize the EFI memory map
  pages       physical page allocator pool
  pci         enumerate PCI devices on the bus
  resources   fixed-pool audit: scheduler tasks, process registry, windows, page-table carve-out, and per-process ring bounds
  timer       interrupt controller + timer status
  uaccess     user-memory copy diagnostics (valid, fault, recovery)
tasks / processes
  exec        load a user program from the ESP and enter it at EL0
  kill        terminate a running process (kernel-owned lifetime)
  mbox        per-process IPC mailbox: pending messages and drain counters
  procs       process registry: image, address space, lifecycle, exit status
  ps          process status table: PID, name, state, memory footprint, CPU ticks, and executor task per live/exited process (M22 D6)
  spawn       spawn the lifecycle demo task
  strace      trace a program's syscalls: 'strace exec APP.BIN [args]' arms the tracer around an exec and prints one line per syscall; 'strace off' disarms
  sym         crash-report symbol table: 'sym' lists symbols loaded from the last ELF exec; 'sym <file>' parses an ELF's symtab from disk
  syscalls    numbered syscall table and counters
  tasks       tick-driven task scheduler status
storage
  cat         print a file from the ESP (by name or /path)
  ls          list files on the ESP (or a directory by path)
  mount       switch the active FAT volume (esp or data)
  write       write text to a file on the ESP
networking
  net         virtio-net transport + RX + ARP + ICMP + UDP + DHCP + TCP + DNS: device DID, MAC, queues, feature bits, RX counters ('net recv' prints received frames; 'net ip <a.b.c.d>' sets the static IP; 'net arp [<a.b.c.d>]' shows/resolves the ARP table; 'net ping <a.b.c.d>' sends an ICMP echo request; 'net udp [listen <port>|close <port>|send <addr> <port> <len>|recv [<port>]]' drives UDP; 'net dhcp' runs the bounded DHCP client one step per invocation; 'net tcp [connect <addr> <port>|send <len>|recv|close|reset]' drives the bounded TCP client; 'net dns <hostname> [<server>]' resolves DNS A-records)
  netsend     send a known Ethernet frame (bounded staging, TX + used-ring drain)
graphics / input
  font        terminal font size: small 8x8 (default), medium 16x16, large 24x24 (M20-U1)
  input       keyboard/pointer event FIFO: armed state, occupancy, drop count, last keyboard + pointer events
  roadpops    Road Pops framebuffer console: armed/dirty/present counters (the boot terminal on the screen)
  screen      virtio-gpu transport + framebuffer: device DID, features, scanout, status, re-arm ('screen fill <rrggbb>' fills the framebuffer and flushes it to the scanout)
  text        framebuffer text: text region, cursor, scrollback ('text put <string...>' renders + flushes to the scanout; 'text clear' clears; 'text putraw' skips the trailing newline; 'text fontdebug [on|off]' missing-glyph stats)
  usb         XHCI host controller: `usb` transport report, `usb devices` enumerated HID devices, `usb report` last HID report
  dui         Driving Award window manager: registry (with owner pids), z-order, focus, hit-testing ('dui focus <n>' focuses; 'dui raise <n>' raises; 'dui lower <n>' lowers to back; 'dui move <n> <x> <y>' moves a user window; 'dui close <n>' releases a user window; 'dui list <pid>' filters by owner; 'dui hit <x> <y>' hit-tests; 'dui cycle' cycles focus like Alt+Tab)
system
  beep        synthesize + play a sine through the virtio-snd PCM path ('beep <freq> <ms>' — reports the full control flow + submit/drain accounting)
  calc        calculator utilities: 'calc history' shows saved calculation history from /data/calc_hst.txt
  clear       clean up the crime scene
  compose     list available Alt+key compose sequences for accented characters
  crash       list recent crash tombstones from /data/crash/
  clip        copy/paste the shared kernel clipboard ('clip <text...>' sets it, 'clip' prints it)
  color       toggle ANSI terminal colors ('color on'/'color off'; 'color' shows current)
  echo        repeat your regrettable decisions
  help        grouped command catalog and per-command/per-topic help
  random      print n random bytes from the seeded CSPRNG (hex)
  reboot      restart the machine
  repeat      repeat text, safely bounded
  sh          run a script file of shell commands ('sh <script>' executes it line by line; 64 lines max, 256 chars per line; '#' comments; 'exit' stops early)
  settings    persistent configuration: `settings [list]`, `settings get <key>`, `settings set <key> <val>`, `settings reset`
  sound       virtio-snd transport: device DID, class, status, control-queue state, device-config counts (jacks/streams/channel-maps), re-arm; stream-state control: 'sound volume <0-100>' and 'sound mute <on|off>'
  shutdown    request power-off
type 'help <command>' for details on a single command.
type 'help <topic>' for a topic page (networking, windows, storage, graphics).
