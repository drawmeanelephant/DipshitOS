PULSE.ELF — third-party software notices
==========================================

The PULSE.ELF guest binary (M72c, built by
tools/go/build-pulse.sh) statically links the following
third-party Go modules. Their sources are NOT vendored in this
repository: they resolve into the host Go module cache at build time
and are staged/overlaid, never copied in-tree. This file carries the
copyright and permission notices their licenses require for binary
redistribution.

Pinned versions below match `*_VERSION=` in tools/go/build-pulse.sh
plus MVS resolution at the time of writing (`go list -deps` over the
pulse import closure for GOOS=virelai GOARCH=arm64). Bumping any
pinned version requires re-resolving and updating this file; the
build script fails if the pinned version strings are absent here.

Note: golang.org/x/sys is in the module graph but contributes zero
packages to the virelai link — the Virelai platform shims
(tools/go/overlay/charm/*_virelai.go) remove every host-syscall use —
so it is not a linked dependency and is omitted.
