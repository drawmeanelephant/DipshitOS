## Notes

Deterministic claim ID from `bash tools/status/claim-id.sh '<branch>' 'gic-timer-interrupts'` = 7948.

Discovery: the VZ XSDT carries FACP/GTDT/**APIC**/MCFG (claim 0013 observed). The MADT (sig "APIC") has the GIC distributor (type 0x0B, base @+16) and — for GICv3 — the redistributor (type 0x0D, base @+16); the GTDT has the EL1 physical-timer interrupt (GSIV @+56, conventionally PPI 30). ACPI reads are pre-exit only (post-exit window reads hang on VZ, claim 0013).

Programming (post-MMU, kernel owns EL1): GICv3 = distributor EnableGrp1, redistributor wake + PPI-30 group1/enable/priority, then the system-register CPU interface (ICC_SRE_EL1 → ICC_PMR_EL1=0xff → ICC_IGRPEN1_EL1 → IAR1/EOIR1). GICv2 = distributor + GICC MMIO. Timer = CNTFRQ_EL0, CNTP_CVAL_EL0 = CNTPCT_EL0 + period (1 s), CNTP_CTL_EL0 enable. IRQs stay masked until everything is armed, then `daifclr #2`. The IRQ handler acks (IAR), re-arms + increments ticks, EOIs, and the claim-9746 stub `eret`s — the shell continues.

Gate evidence: class A — `zig test kernel/src/gic.zig` + `timer.zig` (MADT/GTDT fixture parsing, GICv3 discovery + fallback layout, period math, command host behavior) + the whole `verify-unit-tests.sh` set (84 tests, 12 new) + updated transcript + build/image/inspect/context/swift + coordination. Class B — `tools/verify-live-timer.sh` boots VZ, scripts `timer`, and asserts in `vm-serial.log`: the `timer` command showing `armed=1` (GIC + timer initialized, 24 MHz), the poll-driven heartbeat (`timer heartbeat ticks=N` growing across the idle loop — the CNTP comparator firing, consumed by ISTATUS/CNTPCT poll since VZ never signals), and the follow-up echo reply. 3/3 boots.

The delivery wall is evidenced end to end (all read-backs in `vm-serial.log`, diagnostics removed after capture): GICD @ 0x10000000 live (`GICD_CTLR=0x50` → ARE_NS, GICv3; TYPER sane), GICR @ 0x10010000 **RAZ/WI** (TYPER, WAKER, IGROUPR0, ISENABLER0, ICFGR1 all read back 0 — PPI/SGI config is inert; no PrimeCell CIDR anywhere), CPU interface live (ICC_SRE=7, PMR fully writable, IGRPEN1=1), the timer provably fires (`ISTATUS=1` after the comparator passes, CVAL unchanged — a hardware tick occurred but was never routed), the **distributor SPI path works** (SPI 32 isen/igrp/prio all took), the virtio device raises INTx (`ISR=0x1` after a used-ring notification), yet HPPIR0/HPPIR1 stay 1023 and `handled_delta=0` — no exception is ever taken. Conclusion: VZ's GIC is a config-accepting stub; delivery is impossible from the guest side (the runner's `VZGICConfiguration` API is not exposed on this macOS SDK).
