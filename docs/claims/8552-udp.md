## Notes

**Why this card:** N4 put the guest on the internet layer (ICMP echo
only). UDP is the smallest real transport: no connection state, a
bounded port space, and a checksum that is pure math. It gives the stack
its first demultiplexing surface — ports — which the later syscall seam
will need. Every pattern is proven: bounded TX (N1), IPv4 validation +
protocol dispatch (N4), bounded BSS state (the N3 table / N2 FIFO), the
runner's capture-thread packet inspection, and the script1/script2
settle gate pattern. The loopback path is the new honest piece: sending
to our own IP must deliver locally WITHOUT a device round trip — pure
logic, host-testable in class A, then exercised live.

**Observe, don't assume (claim-time questions):** (a) does the device
touch any UDP field (checksum offload)? — the N1–N4 observations say no
offloads are negotiated and frames pass raw; the byte-exact captures pin
it. (b) the net device's used-buffer IRQ line remains unobserved (the
N2/N3/N4 record) — drain stays polled.
