## Notes

**Why this card:** the address is still typed by hand (`net ip`); a
guest on the N7 NAT network realistically needs to lease one. N8 is the
bounded RFC 2131 client on the N5/N6 UDP layer — the honest way to
configure a guest on the NAT network, and the last rung before the
roadmap's TCP sketch.

**The claim-time question (phase 2):** does the VZ NAT attachment serve
DHCP? The common VZ NAT shape serves the 192.168.64.0/24 pool with a
DHCP server. If it does, the guest leases a real address and the phase-2
gate proves the client against a real server; if it does NOT, phase 2 is
honestly blocked with the observation recorded — never faked.

**Deterministic phase 1:** the crafted OFFER/ACK carry a FIXED
gate-assertable lease {ip 10.0.0.2, mask 255.255.255.0, gateway
10.0.0.1, server id = the lease IP, lease 3600s} with the guest's xid
echoed byte-exact; the gate asserts the bound line, the counters
(discover=1, offer=1, request=1, ack=1, mal=0), and the byte-exact
DISCOVER/REQUEST shapes in the capture.
