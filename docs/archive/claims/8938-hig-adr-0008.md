## Notes

Milestones 0–7 shipped a complete machine but a spartan interface. This card
pins the contract the milestone-eight usability cards implement, so they land
as one coherent system rather than N ad hoc features.

**ADR 0008** decides: D1 command grammar + grouped `help`/`help <cmd>`/
`help <topic>`; D2 prompt/editing (bounded history, cursor movement,
Ctrl-A/E/K/U/L, Delete, tab completion, byte seam `\b \b`/`\r\n`/`^C\r\n`
preserved); D3 the `usage:`/`error:`/`unknown command` shapes with no panics;
D4 Driving Award visible focus + click=focus/raise + keyboard cycling + a
title bar (name + owning pid); D5 the `about`/`welcome`/motd/`sysinfo`
support surface; D6 enforceability — each guideline names the gate that
enforces it.

**march-m8.md** records the U0–U8 ladder (U1 help/catalog, U2 editing/history,
U3 error/usage contract, U4 pointer focus + cursor, U5 window HIG, U6
first-boot, U7 sysinfo, U8 persistent settings), each with its gate, plus the
collision-free agent split (U3 after U1, U4+U5 one owner, U6/U7 serialized)
and a "docs follow-ons" note to post the source-available-not-open-source
license clearly on the public site.
