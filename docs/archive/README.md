# docs/archive — archived one-shot prompts

Files here are one-shot agent prompts from **completed** milestones. They
are history, not active plans: do not feed them to an agent as a work
order, and do not treat their milestone expectations as current state.
`> ARCHIVED`-labeled files elsewhere in `docs/` are frozen history for the
same reason. The canonical, always-current answers are `docs/status.md`,
`docs/roadmap.md`, and `docs/march-m3.md`.
