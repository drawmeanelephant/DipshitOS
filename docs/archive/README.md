# docs/archive — archived one-shot prompts and frozen designs

Files here are one-shot agent prompts, designs, and trackers from
**completed** milestones (prompts, designs, and the M1.5 march tracker
moved here when their milestone closed; see the `git log` for the move
commit). They are history, not active plans: do not feed them to an agent
as a work order, and do not treat their milestone expectations as current
state. The canonical, always-current answers are `docs/status.md`,
`docs/roadmap.md`, and `docs/march-m3.md` — keep completed-work docs out
of `docs/` root so the root holds only active documentation.
